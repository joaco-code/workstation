# AI Development Platform

## Objetivo

La AI Development Platform centraliza la configuración, conocimiento y componentes necesarios para integrar asistentes de IA dentro de la workstation de desarrollo.

Su objetivo es proporcionar un entorno consistente, seguro y mantenible para herramientas como Claude Code, Codex CLI y futuros asistentes.
