# 🤖 AI Engineering Platform Framework

Este directorio centraliza la estrategia multi-modelo, matriz de comparativa, guía oficial de uso, benchmarks y buenas prácticas para la interacción con los ecosistemas de IA (**Claude, OpenAI Codex, GitHub Copilot y Gemini**) en el desarrollo de los proyectos satélites (.NET 10, MSSQL, Azure, DWH).

---

## 📊 Matriz de la Plataforma de IA

| Módulo | Archivo | Propósito Principal |

| **Definición de Responsabilidades** | `responsibilities-matrix.md` | Matriz RACI y asignación de roles por herramienta de IA en el ciclo de vida del software. |

| **Buenas Prácticas** | `best-practices.md` | Normas de interacción, patrones de prompting, seguridad y prevención de alucinaciones. |
