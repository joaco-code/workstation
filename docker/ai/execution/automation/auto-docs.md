# ⚡ Automation: Documentación Automática desde Código

## Propósito
Extraer metadatos de código fuente C# (.NET 10) o scripts T-SQL y generar la documentación en Markdown dentro de `docs/` en los proyectos satélites.

## Capacidades
* **Endpoints .NET:** Genera tablas con métodos HTTP, rutas, DTOs de entrada/salida y códigos de estado HTTP.
* **Esquemas MSSQL:** Genera diccionarios de datos en Markdown leyendo los tipos de columnas, nulos y comentarios de tablas/vistas.
