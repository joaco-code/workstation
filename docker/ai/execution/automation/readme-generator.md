# 📝 Automation: Generador de README

## Propósito
Escanear la estructura de cualquier subdirectorio en la solución y redactar/actualizar su `README.md` manteniendo la jerarquía y formato visual estándar de la plataforma.

## Reglas de Ejecución
1. Lee los archivos presentes en el directorio objetivo.
2. Identifica el propósito de cada archivo mediante su encabezado o código.
3. Genera una tabla de contenido, descripción general y comandos rápidos de ejecución.
