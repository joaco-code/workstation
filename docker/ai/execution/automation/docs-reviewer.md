# 🔍 Automation: Auditor y Revisor de Documentación

## Propósito
Verificar la salud global de la Base de Conocimiento (`knowledge/`).

## Validaciones Automáticas
* Enlaces relativos de Markdown rotos.
* Ausencia de tablas o descripciones en archivos `README.md`.
* Incoherencias entre el plan/roadmap y los archivos implementados.
* Presencia de términos u opciones en desuso (ej. versiones viejas de .NET).
