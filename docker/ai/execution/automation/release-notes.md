# 🚀 Automation: Generador de Release Notes

## Propósito
Consolidar el resumen ejecutivo de una nueva versión o despliegue de un sistema satélite (ej. Admisiones v1.2.0).

## Estructura de Salida
* **Nuevas Funcionalidades:** Cambios visibles para los usuarios o el negocio.
* **Mejoras Técnicas / Backend:** Optimizaciones en .NET 10, queries T-SQL o índices.
* **Cambios en DWH / Staging:** Nuevas vistas o modificaciones en contratos de sincronización.
* **Variables de Entorno Necesarias:** Nuevos secretos que deben registrarse en Azure Key Vault.
