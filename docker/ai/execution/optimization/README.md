# 🚀 Marco de Optimización de Inteligencia Artificial

Este directorio define las estrategias, métricas y políticas para maximizar el rendimiento, minimizar costos operacionales y optimizar el consumo de tokens en las interacciones con Claude Code, OpenAI Codex CLI y los agentes del ecosistema.

---

## 📊 Matriz de Guias de Optimización

| Dimensión | Archivo | Objetivo Principal |
| :--- | :--- | :--- |
| **Contexto** | `context-optimization.md` | Gestión eficiente de la ventana de contexto, poda de información y empaquetado. |
| **Rendimiento** | `performance-optimization.md` | Reducción de latencia, ejecución paralela de herramientas MCP y streaming. |
| **Coste** | `cost-optimization.md` | Presupuesto de tokens, ruteo dinámico de modelos y Prompt Caching. |
| **Prompts** | `prompt-optimization.md` | Compresión de instrucciones, estructura XML/JSON y eliminación de redundancia. |
| **Memoria** | `memory-optimization.md` | Persistencia de estado, condensación de historias y gestión de RAG. |
| **Benchmarking** | `benchmarking.md` | Métricas de evaluación, tests de regresión y calidad de código .NET 10 / MSSQL. |
