# 📑 Alineación con ISO 27001

Aunque este entorno de workstation puede no estar formalmente certificado, nuestras prácticas operativas se inspiran en los controles del estándar ISO 27001 para mantener un Sistema de Gestión de Seguridad de la Información (SGSI) robusto.

## Controles Implementados

| Dominio ISO | Implementación en la Workstation |
| :--- | :--- |
| **Control de Acceso** | Uso exclusivo de cuentas nominales y prohibición de credenciales hardcodeadas. |
| **Criptografía** | Cifrado de datos en reposo y conexiones forzadas por TLS/HTTPS. |
| **Seguridad Operacional** | Backups automatizados, monitoreo de contenedores y segregación de redes en Docker. |
| **Gestión de Proveedores** | Evaluación estricta de imágenes base de Docker y dependencias de NPM/Python. |
| **Gestión de Incidentes** | Procedimientos documentados para contención y recuperación rápida. |
