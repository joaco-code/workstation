# Langfuse

## 1. Purpose

Langfuse is the AI observability platform selected for the AI Development Platform.

Its purpose is to provide visibility into Large Language Model (LLM) interactions by collecting telemetry, execution traces, prompts, costs, latency and quality metrics.

Langfuse enables the platform to monitor, analyze and continuously improve AI-powered applications.

---

# 2. Overview

Langfuse is an open-source observability platform designed specifically for LLM applications.

Unlike traditional monitoring tools, Langfuse understands AI workloads and records the complete lifecycle of prompt execution.

It provides:

- prompt tracing;
- execution history;
- latency metrics;
- token usage;
- cost tracking;
- evaluation workflows;
- debugging support.

Langfuse is an observability platform rather than an inference engine.

---

# 3. Platform Role

Within the AI Development Platform, Langfuse provides:

- LLM observability;
- execution tracing;
- prompt lifecycle management;
- quality evaluation;
- usage analytics;
- engineering insights.

Langfuse supports continuous improvement of AI systems.
