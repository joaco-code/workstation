# 11 - n8n

> Documentación de la instalación, configuración y administración de n8n como plataforma principal de automatización e integración de servicios.

---

# Objetivo

Este documento registra la instalación, configuración y utilización de n8n dentro de la workstation.

n8n será la plataforma principal para el desarrollo de automatizaciones, integraciones, agentes de IA y orquestación de procesos.

La instalación se realizará mediante Docker y todos los datos serán persistentes.

---

# ¿Qué es n8n?

n8n es una plataforma de automatización de flujos (workflows) que permite integrar aplicaciones, APIs, bases de datos y modelos de Inteligencia Artificial mediante una interfaz visual y nodos reutilizables.

En esta workstation será uno de los componentes principales de la arquitectura.

---

# Rol de n8n

n8n será utilizado para:

- Automatización de procesos.
- Integración entre sistemas.
- Agentes de IA.
- Orquestación de LLMs.
- Integración con Microsoft 365.
- Integración con Azure.
- Integración con bases de datos.
- Automatización personal.
- Automatización institucional.
- APIs internas.

---

# Persistencia

Los siguientes datos deberán persistirse:

- Base de datos PostgreSQL.
- Configuración de n8n.
- Archivos adjuntos.
- Workflows.
- Variables.
- Credenciales (cifradas).

Nunca se utilizarán contenedores efímeros para el entorno principal.

---

# Variables de entorno

La configuración deberá almacenarse en:

```
.env
```

Ejemplos:

- URL pública.
- Puerto.
- Usuario administrador.
- Contraseña.
- Clave de cifrado.
- Parámetros de PostgreSQL.

No deberán incluirse secretos en el `docker-compose.yml`.

---

# Integración con Docker

Toda la infraestructura se administrará mediante:

```
docker compose
```

No se utilizará `docker run` para el entorno permanente.

---

# Integración con PostgreSQL

n8n utilizará PostgreSQL como base de datos principal.

La instancia PostgreSQL será compartida con otros proyectos únicamente si se documenta expresamente.
